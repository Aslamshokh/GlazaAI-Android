# GLAZA AI — Android (Kotlin/Jetpack Compose)

Нативное Android-приложение, те же 6 режимов, что в web- и iOS-версиях (Валюта, Текст,
Предметы, Документы, Штрих-коды, QR-коды), тот же backend (`glaza-ai-backend`).

**Хорошая новость по сравнению с iOS:** здесь не нужен ни Mac, ни Apple ID, ни Sideloadly.
Собранный `.apk` подписывается автоматически временным отладочным ключом Android (его
подпись действует около 30 лет — никаких переустановок каждые 7 дней) и устанавливается на
телефон одним касанием.

Честно о том, что я не проверял сам: у меня в этой среде нет Android SDK (сетевой доступ к
серверам Google, откуда он скачивается, здесь запрещён политикой), поэтому я не смог
скомпилировать проект сам — весь код написан и очень внимательно вычитан вручную. Соберётся
он на бесплатном облачном сервере GitHub Actions, у которого Android SDK уже есть "из
коробки". Если сборка всё же упадёт — пришлите мне текст ошибки из лога (вкладка
Actions → клик по упавшему запуску → разверните шаг с крестиком), и я пришлю исправление.

## Шаг 1 — выложить проект на GitHub

Вы уже делали это для iOS-версии — процесс тот же самый, просто для новой папки.

1. На https://github.com создайте новый репозиторий, например `glaza-ai-android` (Private,
   без автоматического README/.gitignore/license).
2. В PowerShell, в папке с этим проектом (куда распаковали архив):

```powershell
cd путь\до\GlazaAI-Android
git init
git add .
git commit -m "GLAZA AI Android app"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/glaza-ai-android.git
git push -u origin main
```

Если попросит авторизацию — используйте тот же Personal Access Token, что создавали для
iOS-репозитория (с правами `repo` и `workflow`), в виде:

```powershell
git remote set-url origin https://ВАШ-ЛОГИН:ВАШ_ТОКЕН@github.com/ВАШ-ЛОГИН/glaza-ai-android.git
git push -u origin main
```

## Шаг 2 — запустить сборку

1. На странице репозитория откройте вкладку **Actions**.
2. Слева выберите **Build debug APK** → справа кнопка **Run workflow** → **Run workflow**
   ещё раз для подтверждения. (Если это не первый пуш — сборка могла запуститься уже сама.)
3. Подождите пару минут, обновляя страницу — напротив запуска появится зелёная галочка.
4. Откройте этот запуск → внизу раздел **Artifacts** → скачайте **GlazaAI-debug-apk**
   (это `.zip`, внутри — сам `app-debug.apk`).

## Шаг 3 — установить на телефон

1. Перенесите файл `app-debug.apk` на Android-телефон любым способом — через USB-кабель и
   проводник Windows (папка "Загрузки" на телефоне), через Google Диск / Telegram "Избранное" /
   почту себе — что угодно, лишь бы файл оказался на телефоне.
2. На телефоне откройте этот файл (например, через приложение "Файлы" или уведомление о
   скачивании).
3. Android спросит разрешение на установку из этого источника ("Install unknown apps") —
   разрешите для того приложения, через которое открываете файл (Файлы/Chrome/Telegram и т. п.).
   Это стандартный диалог Android, появляется один раз для каждого источника.
4. Нажмите **Установить**. Иконка «ИИ ГЛАЗ» появится на телефоне — готово, без каких-либо
   дополнительных шагов, сертификатов или программ на компьютере.

Если захотите переустановить позже — просто повторите шаг 3 с тем же или новым `apk`, подпись
не истекает.

## Настройка backend в приложении

Во вкладке **Настройки** самого приложения укажите адрес вашего backend (тот же, что
используете для web- и iOS-версий — локальный IP или адрес туннеля, например
`http://192.168.1.66:8000`) и `X-API-Key`, если он задан на сервере.

## Что реально работает в приложении

- **Валюта** → `/currency/recognize`
- **Текст** → `/ocr/recognize`
- **Документы** → тот же общий OCR, что и «Текст» — backend не делает отдельного разбора
  полей паспорта/ID, это честно написано в подзаголовке режима в самом приложении
- **Предметы** → `/vision/describe-scene`
- **Штрих-коды** → сканируются нативно на устройстве (библиотека ZXing, без зависимости от
  Google Play Services), затем код ищется через `/barcode/{code}` (Open Food Facts)
- **QR-коды** → сканируются нативно; если это ссылка, приложение предложит открыть её
  в браузере — backend для этого не нужен вовсе

## Если позже появится свой компьютер с Android Studio

Откройте папку `GlazaAI-Android` в Android Studio (File → Open) — она сама скачает нужные
версии Gradle/Android SDK и соберёт проект, можно будет запускать прямо с компьютера на
подключённый по USB телефон одной кнопкой ▶, без GitHub Actions.
